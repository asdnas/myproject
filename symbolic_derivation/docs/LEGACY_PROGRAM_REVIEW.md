# 旧程序审查

## 文件结构

| 文件 | 作用 |
|---|---|
| `config.py` | 人工填写唯一一组 8 段 `v1`、`v2`、`time` 参数；当前启用的是 D 模式参数，文件末尾还注释保留了一组 G 模式参数。 |
| `engine.py` | 符号递推、梯形面积约束求 `I0`、数值代入和波形点生成。 |
| `run_example.py` | 运行当前配置，打印标幺化 `I0...I8`。 |
| `plot.py` | 绘制数值半周期电流波形；当前入口未调用它。 |
| `说明.txt` | 旧使用说明，但部分描述已经过时。 |
| `__init__.py` | 导出 `engine.py` 和 `plot.py` 的接口。 |
| `参考论文.pdf` | 龚邻骁等论文，附录含表 A1。 |

目录不是 Git 仓库。扫描时未发现独立 README、测试文件或其他 D/G 配置文件。

## 运行方法与实际状态

在项目根目录运行：

```powershell
python run_example.py
```

2026-06-11 实测可以运行，输出当前配置的标幺化 `I0...I8`。`run_example.py`
只做符号输出，不包含 `说明.txt` 所称的数值参数编辑、LaTeX 输出和绘图流程。

## 数学逻辑

1. `config.py` 的 `MODE_CONFIG["segments"]` 必须恰好有 8 段。
2. 每段持续时间为
   `((c_D1*D1 + c_D2*D2 + c_phi*phi + c_const) / (2*fs))`。
3. 旧代码实际使用 `k=(v1*V1 + v2*n*V2)/L`。
4. 递推 `I[k+1]=I[k]+k[k]*t[k]`。
5. 对每段计算梯形面积 `(I[k]+I[k+1])*t[k]/2`。
6. 使用 `sympy.solve(sum(area_list), I0)` 求 `I0`，即明确使用总面积为零约束。

当前 D 配置还满足 8 段总时间为 `2*Th=1/fs`、`I8=I0`。因此旧代码中的
“8 段”覆盖完整开关周期，而不是一个 `Th=1/(2fs)` 半周期；旧注释称“半周期”
与实际配置不一致。

## 输入与输出

输入是单个全局人工配置以及符号 `V1,V2,n,L,fs,D1,D2,phi`。`engine.evaluate`
另支持数值参数，但当前入口没有调用。

输出包括符号 `I0...I8`；底层 `details` 还包含段时间、斜率、原始/代入后的电流和面积。
没有事件名、开通/关断分类、CSV 或 Markdown 自动输出。

## 与本次目标描述的差异

- 新程序已确认统一使用 physical 定义 `vL=v1_state*V1-v2_state*n*V2`。
  legacy 通过 `v2_physical=-v2_legacy` 转换后与旧加号公式严格等价。
- `说明.txt` 写成减号斜率，但 `config.py` 文档和 `engine.py` 实现均为加号。
- `说明.txt` 称当前 8 段全为零、入口会数值计算和绘图，均与实际文件不一致。
- 旧程序没有记录段边界对应哪个开关事件，也没有关断电流分析。

| segment | v1 | v2 | time expression | legacy slope |

| 1 | 1 | 1 | `(D1/2+D2/2+phi-1)Th` | `(V1+nV2)/L` |

以及段时长非负条件对应表 A1 的 D 约束，本审查将其识别为 D 模式。
