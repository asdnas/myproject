# 事件表达式审查

## 当前阶段：电压跳变事件

当前分段主依据改为 `VoltageEdge`，不要求先恢复完整八管 on/off 事件。

- `primary`：仅原边桥输出电压变化；
- `secondary`：仅副边桥输出电压变化；
- `both`：原副边电压同时变化；
- `period_boundary`：完整周期闭合边界。

统一时间起点规则来自用户补充并以参考论文图 3 为依据：

1. `t=0` 时原边电压为 `-V1`；
2. 经过 `D1*Th` 后，原边电压由 `-V1` 变为 `0`；
3. 完整周期为 `Ts=2*Th=1/fs`。

A-H 均已生成满足上述规则的 VoltageEdge/VoltageSegment。D/G 还可从 legacy
人工分段独立恢复并与通用生成结果逐段一致。边界暂不强行命名为具体开关事件。

## 图 3 与 legacy 的使用边界

论文图 3 用于判断 A-H 模式的电压波形相对次序和后续人工核对。legacy D/G 参数
用于恢复 D/G 每段的持续时间与物理电压状态。当前没有把图 3 中标注的开通时刻
直接当成完整周期绝对时间公式。

## 后续完整开关事件

`events.py` 仅保留为后续层。完整八管 on/off、状态更新和开关电流提取将在
VoltageSegment 验证完成后再建立。`tS4=0` 不作为当前或最终事件表达式假设。
