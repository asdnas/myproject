# 表 A1 模式约束录入

来源：`参考论文.pdf` 附录 A，表 A1。论文中的 `Φ` 在代码中统一写作 `phi`。
所有模式还统一附加 `0<=D1,D2,phi<=1`。表中约束清晰，A-H 均已成功录入。

| 模式 | 原始约束（`Φ` 改写为 `phi`） | SymPy 录入状态 |
|---|---|---|
| A | `1+(D2-D1)/2 <= phi <= 1+(D1-D2)/2` | 成功 |
| B | `(D1+D2)/2 <= phi <= 1+(D2-D1)/2 & 1-(D1+D2)/2 <= phi <= 1+(D1-D2)/2` | 成功；用户已确认 `&` 表示“且”，两组约束同时成立 |
| C | `(D1+D2)/2 <= phi <= 1-(D1+D2)/2` | 成功 |
| D | `1-(D1+D2)/2 <= phi <= (D1+D2)/2` | 成功 |
| E | `(D1-D2)/2 <= phi <= 1-(D1+D2)/2 & (D2-D1)/2 <= phi <= (D1+D2)/2` | 成功；用户已确认 `&` 表示“且”，两组约束同时成立 |
| F | `(D1-D2)/2 <= phi <= (D2-D1)/2` | 成功 |
| G | `(D2-D1)/2 <= phi <= (D1-D2)/2` | 成功 |
| H | `1+(D1-D2)/2 <= phi <= 1+(D2-D1)/2` | 成功 |

具体 SymPy 关系式见 `symbolic_derivation/mode_constraints.py`。当前无需人工补录。
